## Как пересобрать после правок

1. Заполнить значения в `build/facts.py` (карточка проекта, партии, реклама) — факты зашиты в скрипты, ручные правки в docx при пересборке теряются.
2. Тексты разделов — `build/content_a.py` (титул, реферат, введение, 1.1), `content_b.py` (1.2, 1.3), `content_c.py` (1.4, 1.5, заключение, источники); бизнес-план — `build_bp.py`; отчёт о развитии — `build_dev.py`; приложения — `build_appendices.py`.
3. Запуск из папки `build/` (нужны python3, python-docx, pdfplumber, Pillow, matplotlib, LibreOffice):

```bash
cd build
python3 -I diagrams/make_diagrams.py      # при изменении схем (запускать из build/diagrams)
python3 -I build_report.py                # docx → PDF → страницы содержания → docx → PDF
python3 -I build_bp.py
python3 -I build_dev.py
python3 -I build_appendices.py
python3 -I check_docs.py ../*.docx        # запрещённые слова, нумерация, ссылки на объекты, список [УТОЧНИТЬ]
```

Результат кладётся в `../../out` относительно `build/` — при переносе папки поправить константу `OUT` в скриптах или скопировать файлы вручную.

## Что проверено автоматически

- Шрифт Times New Roman 14, интервал 1,5, отступ 1,25 см, поля 30/15/20/20 мм; подписи таблиц слева сверху, рисунков по центру снизу; сквозная нумерация; на каждый объект есть ссылка до него; содержание совпадает с PDF; счётчики реферата актуальны.
- Нет слов «исследование», НИР, НИОКР, TRL/УГТ, URL в тексте, личных местоимений; адреса сайтов только в перечне источников.
- Ответы отчёта о развитии согласованы с текстом отчёта о работах (сотрудники не привлекались — работы выполнены генеральным директором; выручки нет).
