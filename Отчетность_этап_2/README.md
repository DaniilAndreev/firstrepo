# Отчётность по 2-му этапу гранта «Студенческий стартап» — проект «Вкусноты»

Пакет документов ООО «Вкус Технологии» по теме «вкусноты — производство съедобных музыкальных пластинок из изомальта». Финансовый отчёт в пакет не входит.

Версия 2: структура и оформление приведены к принятой Фондом отчётности проекта «Опти» (отчёт о выполнении работ, бизнес-план, отчёт о развитии).

## Как пересобрать после правок

Факты зашиты в скрипты, поэтому ручные правки в docx при пересборке теряются: либо правьте docx вручную и больше не пересобирайте, либо вносите факты в скрипты.

- `facts.py` — карточка проекта (реквизиты, договор, контакты), составы, закупки, партии, сайт, реклама;
- `fin_model.py` — финансовая модель бизнес-плана (цены, объёмы, затраты, налог АУСН, заём учредителя);
- `build_report.py`, `build_bp.py`, `build_dev.py`, `build_appendices.py` — тексты документов;
- `dx.py` — оформление (профили report / bp / dev / app, таблицы, рисунки, списки, содержание);
- `build_fin.py` — финансовый отчёт и НДФЛ по CSV-выписке банка (реквизиты берёт из выписки, сама выписка в репозиторий не кладётся);
- `check_docs.py` — проверки, `list_utochnit.py` — список меток.

Нужны python3, python-docx, lxml, pdfplumber, Pillow, matplotlib и LibreOffice (содержание заполняется по страницам PDF, сборка в несколько проходов):

```bash
cd build
python3 -I build_report.py
python3 -I build_bp.py
python3 -I build_dev.py
python3 -I build_appendices.py
python3 -I check_docs.py "out/Отчет_о_выполнении_работ_этап_2.docx::13" "out/Бизнес-план.docx::18" "out/Отчет_о_развитии_проекта.docx"
python3 -I list_utochnit.py out
```

Результат — в `build/out/`.

## Что проверено автоматически

- Порядок элементов OOXML (таблицы, ячейки, разделы, абзацы, прогоны) — файлы открываются в Word.
- Сквозная нумерация таблиц и рисунков; на каждый объект есть ссылка в тексте до него; содержание совпадает со страницами PDF; счётчики реферата актуальны.
- Все источники процитированы, ссылок на несуществующие нет; литеры приложений идут в порядке упоминания.
- Нет слов «исследование», НИР/НИОКР, TRL/УГТ (кроме формулировки строки формы отчёта о развитии), личных местоимений; адреса сайтов — только в перечне источников и в отчёте о развитии.
- Сокращения в перечне — только реально встречающиеся в тексте.
- Короткие таблицы не разрываются; у длинных шапка не остаётся внизу страницы с одной строкой, последняя строка не переносится одна.
- Цифры согласованы между документами: 10 вариантов состава, 3 партии, 5 пластинок итогового состава, фокус-группа 5 человек, бюджет Директа 15 000 руб., билборды на двух улицах 6 дней; план продаж и выручки 2027 года в отчёте о развитии совпадает с бизнес-планом.
